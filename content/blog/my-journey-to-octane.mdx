Hammasi ishlayotgan kompaniyamdagi bitta taskdan boshlandi.

Loyihaga yuqori darajada moslashuvchan rich-text editor implement qilishim kerak edi. Shu sababli turli editorlarni o'rganishni boshladim va oxiri [Lexical](https://lexical.dev)'ni tanladim.

## Lexical men o'ylagandan murakkabroq edi

Implementatsiya davomida esa Lexical men o'ylagandan ancha murakkab ekanligini tushundim. Editor state, node hierarchy, command system, update lifecycle, node transforms, selection APIs, serialization va reconciliation... Har kuni yangi narsalarni o'rganardim va tabiiyki, ko'plab muammolarga ham duch kelardim.

Shu paytda men Lexical community'dagi tavakkal bir kishiga, Dominic'ga yozishni boshladim. Tushunmagan har bir narsani so'rardim, u esa nafaqat yechimini, balki nima uchun aynan shunday qilish kerakligini ham tushuntirib berardi.

Keyin esa bilsam — men savollar berayotgan inson Lexical muallifi, React Core Team'da ishlagan va bir nechta mashhur open source loyihalar ortidagi muhandis ekan.

## Typix

Lexical bilan ishlash davomida yana bir fikr tug'ildi: nega uning ustiga o'zim xohlagan developer experience'ni beradigan framework yaratmaslik kerak?

Shu tariqa [Typix](https://www.typix.uz) loyihasini boshladim. Maqsadim Lexical'ni almashtirish emas, balki uning ustiga qulayroq API va plugin arxitekturasini qurish edi. Bir necha oy ishlaganimdan so'ng Typix'ning ilk versiyasini ham e'lon qildim.

## Octane Core Team

Typix ustida ishlayotgan vaqtimda Dominic bilan aloqalarimiz yanada mustahkamlandi. Oradan ko'p o'tmay esa men uchun kutilmagan imkoniyat tug'ildi — [Octane](https://octanejs.dev) Core Team'ga qo'shildim. *(13.07.2026)*

Dastlab documentation va Octane website ustida ishladim. Keyinchalik compiler va runtime qismlarini o'rganishni boshladim, turli portlar va binding'lar ustida ishladim.

Keyin qadam-baqadam Octane core — Compiler va Runtime qismlariga tusha boshladim. Hozirgacha runtime'da 2 ta issue'ni fix qildim; bu yerda Michal'ga ham rahmat aytaman.

Bugungi kungacha 25–30 ga yaqin pull request create qildim.
